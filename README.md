# AI Event Management App

This repository contains the AI Event Management App project.

The original design is available at https://www.figma.com/design/MQWglX4g5xiG1p8odHXtpE/AI-Event-Management-App.

## Running the code

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```
