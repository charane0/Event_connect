⚠️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

  MongoDB won't start?
  → mkdir C:\mongodb_data

  Port 5000 in use?
  → netstat -ano | findstr :5000
  → taskkill /PID <pid> /F

  Backend not connecting?
  → Check mongod is running
  → Check .env MONGODB_URI

  Login not working?
  → Check backend logs
  → Verify MongoDB collections created
  → Clear localStorage in browser
